# 规则基线 v0.1

这是迁移重建的设计基线，不是对原程序所有行为的还原声明。旧原型只有 EXE 和资源，没有源码；尚未运行它核对规则。

## 已观察到的资源

- 豌豆射手 13 帧、向日葵 18 帧；僵尸行走 22 / 进食 21 / 站立 11 帧；阳光 29 帧。
- 卡牌标注：豌豆射手 100、向日葵 50、坚果 50。
- `zhiwu/2` 的 9 张图片内容相同，且与坚果卡牌相同，缺少真正的场上角色图。M11 补充静态图。
- 背景为 1400×600；菜单和结算图为 900×600。M04/M18 统一布局与坐标映射。
- 资源的原始帧率、实际费用执行值、数值平衡及波次尚未确认。

## 本项目采用的初始规则

| 项目 | 初始约定 | 落地模块 |
|---|---|---|
| 游戏形态 | 单人二维按行塔防，单关卡，可重开 | M04/M13/M14 |
| 草坪 | 3 行×9 列，每格 80×100；背景像素 [260,980)×[185,485)，详见 GRID.md | M04 |
| 种植 | 选卡后点击空格，检查费用/冷却/格子有效性后一次性扣费 | M06 |
| 初始阳光 | 150；每个阳光增加 25 | M05 |
| 天降阳光 | 每 8 游戏秒一个，未拾取 10 秒后消失 | M05 |
| 植物费用 | 豌豆 100、向日葵 50、坚果 50 | M06/M11 |
| 植物冷却 | 豌豆 5 秒、向日葵 5 秒、坚果 8 秒 | M06/M11 |
| 植物生命 | 豌豆 100、向日葵 100、坚果 600 | M09/M11 |
| 豌豆 | 单次伤害 20，攻击间隔 1.5 秒，仅攻击同排有效目标 | M08 |
| 普通僵尸 | 生命 200；接触植物后每秒结算 25 伤害 | M07/M09 |
| 僵尸速度 | 用格子宽度/游戏秒定义；M07 在实际场景中确定 | M07 |
| 向日葵 | 种下 7 秒首次产阳光，之后每 10 秒产一个 | M10 |
| 铲除 | 选择铲子后移除目标植物，不返还费用；可取消 | M12 |
| 关卡 | 暂定 3 波；具体数量/间隔在 M13 配置，以课堂演示可完整通关为目标 | M13 |
| 胜负 | 最后一波生成完且敌人清零则胜利；任一僵尸越过防线则失败 | M13 |
| 暂停 | 战斗移动、攻击、生成、冷却和波次同时停止，菜单保持响应 | M15 |
| 音量 | 音乐/音效分别调整，支持静音并跨启动保存 | M17 |

除卡牌可见费用外，上述数值属于新版本设计默认值，并未验证为原版数值。后续为平衡性改动时，在交接记录中写清变更，不追溯宣称旧原版已经如此。
