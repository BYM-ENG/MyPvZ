## 已处理问题

第一次运行（`20261026-233726-331`）在 UBT 进入编译前退出，UAT 退出码 8：

```text
Couldn't find target rules file for target ' -log=P:\Saved\Logs\...'
Result: Failed (RulesError)
```

原因：工程直接映射为盘符根目录 `P:\` 时，UAT 自动生成的 `-remoteini="P:\"` 在嵌套参数中破坏引号解析。Common 新增可选 `-MapParent`，打包脚本将父目录临时映射为 `P:`，使用 `P:\UE5Migration`；M00 构建脚本的默认映射行为保留。盘符占用检查和 `finally` 清理保留，两次脚本均通过 PowerShell 语法解析。

原始失败证据保留于该次忽略日志目录；失败目录不作为通过的交付包。
