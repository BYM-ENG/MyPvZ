## 发现并修复

- 需等待游戏时间推进至少0.5秒再读取相机缓存；只等墙钟时间可能在首帧读到默认投影。
- yaw=+90 从负Y观察与像素X向右相反；最终改用正Y侧相机、yaw=-90，并以源图角点投影验证方向。
- UE5.8的 FSceneView::DeprojectScreenToWorld 会先 TruncToFloat/TruncToInt，曾让边界外的小偏移落入末格。最终使用 LocalPlayer 的实际投影矩阵，在齐次坐标中反投影连续屏幕位置，再由 Board 求平面交点；不截断/夹紧越界点。该问题由±0.25样本实际捕获并回归通过。
- 图形验证在截图前切换阶段以防 Slate 回调重入，先结束PIE再退出。截图通过 SystemLibrary.ExecuteConsoleCommand 路由到玩家 GameViewport 的 Shot；AutomationLibrary.TakeHighResScreenshot 会取编辑器自由视口，不作为游戏画面证据。
