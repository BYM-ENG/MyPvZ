## 已处理的问题与适用范围

- 受限执行环境内 dotnet 未进入构建：停止本次挂起进程，以正常本机权限重试。
- 缺失 NETFXSDK：安装微软签名的 .NET Framework 4.8 Developer Pack，安装退出码 0。
- 中文响应文件路径导致 C1083：脚本使用本项目临时 ASCII 盘符，并移走旧的生成缓存后完成干净构建。
- UE5.8 Python SoftObjectPath 接口：自检脚本使用实际绑定的 `export_text()`，并允许 UE 为加载空世界建立的管理对象。
- 禁用非必需动画插件后默认压缩配置指向不存在插件资源：显式指定引擎自带 fallback 资产，不增加额外插件。
